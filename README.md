# vendor_xiaomi_pisces

Proprietary blobs for Xiaomi Mi 3 TD (pisces), extracted from MIUI
V9.2.3.0.KXCCNEK (Android 4.4) system image.

Generated with `update-files.sh`-style extraction using
device/xiaomi/pisces proprietary list (186 blobs, ~60 MB).

Contents: Tegra HALs (gralloc/hwcomposer/audio/camera/gps/sensors),
NV graphics (libnvrm, libEGL_tegra), OMX, BCM43341 firmware, keylayout.
